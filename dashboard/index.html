How It Works

AI-powered LinkedIn outreach: find prospects, generate personalised messages, and run multi-step sequences automatically.

Tools:
Apollo.io
Sales Navigator
PhantomBuster
Claude AI
Microsoft Graph
Internal
Phase 1 — Setup (one-time)
01
Sync Writing Style
Connect Outlook, pull your recent sent emails, and extract tone, sentence structure, and greeting patterns. Claude uses this to generate messages that sound like you.
Microsoft Graph
Claude AI (analysis)
02
Connect LinkedIn Accounts
Add one or more LinkedIn accounts via PhantomBuster. Each account gets its own session cookie and daily send limits. The system rotates across accounts automatically.
PhantomBuster
03
Design Sequence Template
Build a reusable sequence: choose steps (connect, message, follow-ups), set day offsets, configure event-driven triggers (e.g. message 48h after connection accepted). Save as a template for campaigns.
Sequence Designer
Phase 2 — Find Prospects
04
Search & Import
Search Apollo by title, seniority, industry, location, and company size. Or import a Sales Navigator lead list via CSV. Both land in the Contacts tab ready for campaigns.
Apollo.io
Sales Navigator
05
Create Audience Segments
Group prospects by region, industry, job title, or any filter. Segments feed into campaigns so you can target the right people with the right message.
Internal
Phase 3 — Create Campaign & Generate Messages
06
Campaign Setup
Name the campaign, set the goal and value proposition, pick a segment or select prospects, and assign a sequence template. The wizard walks you through each step.
Campaign Wizard
07
AI Sample Generation
Claude generates a sample LinkedIn message for the first prospect using your writing style, campaign goals, and sales copy principles. Review, refine with feedback, and approve.
Claude AI (generation)
08
Apply to All Prospects
Once the sample is approved, Claude generates personalised messages for every prospect in the campaign — matching the approved tone but tailored to each person's role and company.
Claude AI (bulk generation)
09
Review & Launch
Preview every generated message, edit individual ones, skip leads, or regenerate. When satisfied, launch to enrol all approved prospects into the LinkedIn sequence.

The Orchestrator
Runs every 60 seconds. Checks which leads are due for their next step, respects daily send limits per LinkedIn account, and dispatches actions to PhantomBuster. Handles retries, failures, and cooldowns automatically.

Dynamic Timing

LinkedIn Accounts ⓘ
Each account maps to a person's LinkedIn profile and their PhantomBuster phantoms (automated bots). To set up a new account:
1. In PhantomBuster, clone the Connect + Message phantoms and paste the person's LinkedIn session cookie
2. Note the new phantom agent IDs from PhantomBuster
3. Click "+ Add Account" below and enter the name + phantom IDs
The system auto-detects the LinkedIn profile name when you validate.
